Stage Micing 功能总览（最新版）
==================================================

一、这是什么
--------------------------------------------------
Windows 桌面程序（C++20 / Win32 / GDI+，中文界面），做古典音乐会的
「舞台摆位 + 话筒布局」设计：按真实米制摆乐队、放话筒、连线路，
最后导出舞台/布线图片（PNG）与通道表（PDF）。

二、谁来用
--------------------------------------------------
现场录音师、音响师、广播与录制团队的前期方案人员、
音乐厅/剧院技术统筹、相关专业师生。

三、五个页面
--------------------------------------------------
1. 项目信息：曲目、场地、时间、指挥、系统工程师、录音师、助理、备注；
   舞台宽/深/层高（层高＝吊装设备高度）；三个场地预设；外观配色。
2. 乐器摆位：摆乐队、多选、旋转、SRA 张角、同类乐器全选。
3. 话筒摆位：放话筒、设参数、绑定声部、成组。
4. 通道表：通道清单、排序、翻页、行内编辑、长度模式、导出 PDF。
5. 布线：设备与线缆、自动算长度与容量、点话筒直接选接口。

四、舞台与工程
--------------------------------------------------
- 米制严格 1:1：屏幕像素与米换算固定，任何图标缩放都不影响距离。
- 场地预设：音乐厅 18×12 m、教堂 12×20 m、沙龙 9×7 m；
  切换后整个乐队按半差位移、保持居中。
- 工程文件 .smproj，双击可直接打开（可注册文件关联）。

五、乐器（30 种）
--------------------------------------------------
弦乐：第一/第二小提琴、中提琴、大提琴、低音提琴、竖琴
木管：长笛、双簧管、单簧管、大管
铜管：圆号、小号、长号、大号
打击乐：定音鼓、小鼓、大鼓、锣、钹、木琴、钟琴、打击乐
键盘：三角钢琴、立式钢琴、大键琴、钢片琴
声乐：独唱歌手、合唱歌手
其它：指挥、自定义

每件可改名、角度、位置，并可单独设「颜色」（覆盖调色板，图标以及
绑在它上面的话筒、线缆、标签同步变色，可「恢复默认」）。

六、内置预设（12 个，固定数据，不会被自动整理）
--------------------------------------------------
三管编制·欧式 86 件 / 三管编制·美式 85 件
欧式钢琴协奏 87 件 / 美式钢琴协奏 86 件
古乐团 37 件 / 合唱乐团 154 件 / 合唱+钢琴 66 件
弦乐四重奏 1 / 弦乐四重奏 2 各 4 件
钢琴三重奏 3 件 / 钢琴四重奏 4 件 / 钢琴独奏 1 件
顶栏「预设」弹窗分两列列出全部 12 个：↑↓ 选行、←→ 换列、回车即载入、
Esc 或点「取消」关闭，弹窗始终在窗口内。
载入后恢复该预设自己的原始舞台尺寸、清空话筒、保留接口设备；摆位按归一化
坐标存表，所以换尺寸后位置仍精确。各预设舞台尺寸（与源工程一致，画布自动
适配）：三管编制·欧式/美式、欧式/美式钢协、合唱+钢琴 = 18×12；古乐团 = 14×12；
合唱乐团 = 18×16；弦乐四重奏 1/2 = 9×7；钢琴三重奏/四重奏 = 14×10；
钢琴独奏 = 14×12。人名（Soprano/Alto/Tenor/Bass、圆号 2）随摆位一起保存，
载入后仍然显示。

七、话筒（8 类）
--------------------------------------------------
1. 主话筒：AB 对 / 强度差 / 混合差 / Decca 树；间距、中置、高度、吊装可选。
2. 点话筒：单支，可绑定声部或大类。
3. 领夹话筒。
4. 强度差（XY/MS/Blumlein）：舞台上一个对象、占两个通道、
   有 L/R（MS 为 M/S）型号、无间距参数。
5. 混合差（ORTF/NOS/DIN）：就是两支普通话筒摆好后绑定，
   外观与单支完全一致，中间不画线，成组操作、一条两通道线缆。
- SRA（立体声录音角）：AB 用定位模型计算，强度差用标准表；
  舞台左上角显示数值并画两条射线。
- 成对话筒若标签放不下：左话筒贴左下、右话筒贴右下。

八、绑定（38 个目标）
--------------------------------------------------
具体乐器（含立式钢琴等）＋ 8 个声道：
环绕声道、天空声道、侧展、环境、弦乐组、木管组、铜管组、打击乐组。
- 选择器两级：当前绑定 → 环绕 → 天空 → 侧展 → 弦乐组 → 木管组 →
  铜管组 → 打击乐组 → 平铺乐器 → 环境；悬停大类在左/右弹二级。
- 竖琴不在弦乐组内；键盘与声乐为平铺项。
- 绑定结果同时出现在属性栏、通道表「乐器」列、PDF。

九、编组
--------------------------------------------------
- ≥3 支或组内最远 >5 m 时弹确认框。
- 组内共用一条线缆；布线时各支先汇到组平均中点再走主线
  （Decca 取左右两只见的中点，中置单独一条汇集线）。

十、通道表
--------------------------------------------------
列：通道 / 型号 / 乐器 / 备注 / 路由 / 话筒线长度 / 距主话筒 / 幅角
（表尾另有「布线」汇总块）

- 默认排序：主话筒 → 环绕声道 → 天空声道 → 侧展 → 三角钢琴 →
  立式钢琴 → 大键琴 → 弦乐组 → 木管组 → 铜管组 → 打击乐组 →
  其余乐器 → 自定义 → 独唱 → 合唱 → 环境 → 未分配（最后）；
  组内绑定大类的话筒排最前。
- 距主话筒：到主话筒 L/R 胶囊的平面距离（中置不参与），
  左侧量 L、右侧量 R；成组用组汇聚点。
- 幅角：以 L/R 胶囊中点为原点，舞台竖直向上 0°，右正左负。
- 话筒线长度：点列头在「推荐（标准取整）」与「实际（逐条实长）」间切换，
  模式随工程保存，PDF 同步。
- 左右翻页（每页整行、不滚动），表头每页重复，页底页码。
- 行内编辑：型号、乐器、备注；每页都能用。
- 拖动行排序随工程保存，「自动排序」一键恢复且可撤销。
- 路由列：点击弹出设备列表，选一个即连接（与布线页同一套逻辑），
  该格不产生文字输入框。
- 距主话筒 / 幅角两列只读，点击只选中该行。
- 表尾「布线」块：接口箱 → 声卡等设备间链路，显示通道数与长度。
- 导出 PDF：仅通道表，超页自动分页，页脚页码。

十一、布线
--------------------------------------------------
- 设备：声卡 / 接口箱（模拟与数字合并为一类，含名称、输入通道数）/
  无线接收器；可拖动；超容量或线超长变红提示。
- 连线：右键两个对象；或在布线页点选话筒后，右侧「连接」区块
  直接点设备即连（替换旧线、可撤销、成组整组生效）。
- 长度规则：
  · 普通话筒 = 高度 + 地面路径
  · 吊装 = 吊高 + 吊顶段 + 沿墙段 + 地面段
  · 吊顶段固定走向「目标设备所在侧」的左墙或右墙
  · 成组 = 各支汇集段 + 一条主干
- 线缆标签：「通道号 + 话筒名称」（如 08 话筒 7、04–05 话筒 5、
  13–14 NOS L），设备间主干显示「N 通道」；无线为「无线 N 通道」；
  超容量带「!」。
- 颜色统一：话筒符号、它的线缆、标签文字都取「所绑定声部」的颜色；
  未绑定话筒保持中性色。
- 标签采用全局排版：先放最难放的，再多轮松弛，保证互不重叠、
  不压设备框，并尽量靠近自己的线缆。

十二、舞台显示
--------------------------------------------------
- 四个开关：显示乐器 / 显示话筒 / 显示乐器文字 / 显示话筒文字。
- 文字颜色 = 对应对象颜色；重叠时只做左右最小让位。
- 话筒文字紧贴话筒（3–4 px）；02 页两行（名称 + 绑定），
  05 页单行（编号 + 名称）。
- 同类 ≥3 件：不画外框，只在该区域底部一个「第一小提琴 ×15」，
  逐件小字隐藏；组内混入小乐器时恢复逐件显示。
- 独唱歌手不参与「同类」：摆 3 个以上也各自显示自己的名字，没有
  「独唱歌手 ×N」那样的合并标题（合唱仍作为声部合并成一条）。
- 同类全选：先选中一只，右侧出现「全选 第一小提琴 (15)」；独唱歌手
  没有这一行。
- 线宽：乐器 ×1.2、普通点话筒 ×1.5（领夹/强度差/主话筒不变）。
- 调色板 40 色，按「相邻色差最大」排列（相邻 ΔE ≥ 24），
  40 色互不相同，38 个对象各有独立色与线稿色。

十三、编辑操作
--------------------------------------------------
单击选中、Ctrl+单击加选、Ctrl+A 全选当前图层、
Ctrl+拖动框选、不按 Ctrl 拖动空白平移、中键/空格拖动平移、滚轮缩放、
整体移动/旋转、方向键微调（0.05 / Shift 0.5 / Ctrl 0.01）、
Delete、Ctrl+Z / Ctrl+Y（50 步）、
话筒与乐器混合选择时禁止拖动（提示「话筒与乐器不能一起移动」）。

十四、导出
--------------------------------------------------
1. PDF：仅通道表，超页自动分页。
2. PNG：舞台图或布线图（按当前页），三档倍率
   普通 2× / 高清 4× / 超清 8×（点「导出图片」先选，带预计像素尺寸）。
   - 按内容包围盒出图，包含所有内容（含远离舞台的话筒与设备）；
   - 大图分块渲染再拼合，无接缝；
   - 文字为「小字」：不随倍率放大，落在图面空隙中；
   - 图上方左上角打印项目信息（曲目、场地·时间、指挥/录音等）。
3. 舞台图不再写入 PDF（避免裁切）。

十五、文件与安全
--------------------------------------------------
- 打开 / 保存 / 另存为；.smproj 文件关联可用命令行
  `--register-assoc` / `--unregister-assoc` 或附带 .reg 注册。
- 旧工程兼容：未知旧对象载入时跳过并提示，不影响其余数据。
- 应用锁：顶栏最右挂锁图标为唯一入口；4 位密码，随机盐 + SHA-256
  存 applock.dat（无明文）；设置/修改密码后立即上锁。
  锁定＝只读：可看、切页、缩放、导出、打开/另存；
  任何改数据的操作被拒并提示「已锁定，只读」。

十六、界面与语言
--------------------------------------------------
中文 / English / Deutsch / Français 四语种，界面与导出同步。
页签：项目信息 / 乐器摆位 / 话筒摆位 / 通道表 / 布线。

十七、已知限制
--------------------------------------------------
- 布线走最短路径，不主动避让交叉（交叉只是视觉现象）。
- 45° 折线只允许在舞台后半区使用。
- 调色板中「大号 ↔ 定音鼓」色差偏小（ΔE 5.5），二者非相邻位，
  需要时可为它们单独设自定义颜色。
- 导出为单线程，8× 大图需要数秒（已显示等待光标与进度文字）。
- 忘记应用锁密码没有重置后门。
