# 自动布线（话筒拉线）设计 v1.0 + 分阶段实施计划

## 总体
布线拆三层：**通道逻辑（谁接谁、多少路）→ 设备链路（协议/端口）→ 物理走线（路径美观）**。
所有校验问题在"通道逻辑/设备链路"上判定，反馈到走线（红线 + 感叹号 + 悬停原因）。

## 图层规则
- 01 乐器：只有乐器；02 话筒：乐器可见不可动 + 话筒；**03 话筒拉线**：只有话筒（只显示型号）、接口箱、线缆；乐器全部隐藏（含简化方块）。
- 04 通道表：纯表格。每层只显示自己的对象（01/02 不显示接口箱/线缆）。

## 走廊
不做用户自绘走廊。内置两条策略：
1. 优先走舞台左右侧边 / 台口；
2. 中区话筒：先下到**中线**，沿中线到**舞台后部**，再折向侧边/箱。禁止横穿表演区正面。

## 设备与链路模型
- 话筒：位置、高度、(1/2/3 通道)、spotType。
- 模拟接口箱：位置、通道数（用户填）、接口面朝向、多芯对数。
- 数字接口箱：位置、协议（ADAT/AVB/MADI/Dante/Ravenna）、端口数、每口通道数、接口面朝向。
- 录音室设备：声卡、ADDA（协议、路数、端口）、调音台/交换机。
- Link：两端设备 + 协议 + 通道数 + 线型 + 路径 + 长度。
- 连接拓扑：声卡直连话筒 / 声卡→模拟箱→话筒 / 声卡→数字箱→话筒 / 声卡→数字箱→模拟箱→话筒 / 数字箱串联。

## 采样率（顶部芯片，已实现）
44.1/48/96/176.4/192 kHz，决定协议上限：ADAT 8/4/2/1；MADI 64/32/16/8；AVB 默认 8/stream；Dante/Ravenna 设备配置或默认 16/32。

## 校验（超限 → 线变红 + ! + 悬停原因）
超协议通道、超用户输入通道、协议不匹配、级联超总容量、通道号冲突、无法沿允许区域走线。

## 走线美观规则
0°/45°/90°；折点最少优先；同向成束（束间距 ≥0.25 m）；交叉惩罚最高；避让图标 ≥0.15 m、文字 ≥0.1 m、电源线 ≥0.3 m；接口箱线只从接口面一侧接入。

## 长度
折线长 × 1.08 + 两端各 1 m + **全程额外预留 3 m**；束取最长；输出线缆清单。

## 分阶段计划
- **P1（先做）**：数据模型 + 03 图层骨架 + 接口箱对象（放置/删除/属性：类型、协议、通道数、朝向）+ 设备清单（声卡/ADDA 面板）；线缆先用"直连折线"占位。
- **P2**：自动路由（侧边/中线策略 + 折线 + 束）+ 通道分配。
- **P3**：校验告警（红线/感叹号/悬停）+ 通道表联动（链路/长度列）。
- **P4**：PDF（布线图 + 线缆清单）、参数面板、手动调整。

### 走廊路由（`src/Cabling.cpp`）
- 只用 0°/45°/90°：`OrthoAppend()` 先走 45° 斜段（较短轴）再走 0°/90° 直段。
- 侧三分之一话筒 → 就近舞台侧边；中三分之一话筒 → 先回中线 `x = stage.w/2`，
  沿中线到台口 `y = stage.d`，再折向设备一侧；目标在舞台内则直连。
- 平行线按 lane 索引偏移 0.12 m（中线 / 侧边 / 接口面到达点都偏移），
  接口正面最多 ±0.34 m，避免多根线挤在同一点。
- 设备优先级：无线话筒 RX → 模拟箱 → 数字箱 → 声卡 → ADDA；同优先级取走廊长度最短。
- 容量：模拟箱 / 接收器 = 通道数；数字箱 / 声卡 / ADDA = 端口 × min(每口, 协议上限)。
  放不下 → 红色「!」标记 + 状态栏警告，话筒不分配。
- 干线：每个用到的箱自动连到声卡（数字箱按自身协议），通道数 = 该箱已用通道数。

### 线缆长度 / 校验
- 普通线缆：折线 × 1.08 + 2 m（两端）+ 3 m 预留。
- 吊装话筒（见下）：四段之和 × 1.08 + 2 + 3。
- **协议长度上限表**（`ProtocolMaxCableLen()`，`src/Model.h`）：
  ADAT 4 m（规格约 5 m，留余量）｜MADI / AVB / Dante / Ravenna 100 m｜模拟（含无线接收器
  输出）200 m。与通道上限表相邻，方便后续调整。
- 校验：通道数超任一端容量 **或** 长度超协议上限 → 05 线缆变红 + 标签「!」，
  悬停状态栏给出原因（`CableProblemText()`）；03 对应行链路前加「!」并变红；
  04 连线变红加粗，标签带「!」，悬停同样给出原因。
- 自动布线选择数字箱时若会超长（ADAT > 4 m）→ 直接跳过该候选，回落到模拟箱 / 声卡，
  无人可接则按容量告警处理。

### 04 拓扑图

### 吊装话筒（Flown）
- `Item::flown` + `Item::height`；`Project::ceiling`（默认 8.0 m，3–20 m 限幅），
  02 右栏勾选框「吊装」+「高度 (m)」（**主话筒也有这个输入框**，吊装长度按它算），
  项目信息区「层高 (m)」。
- 长度模型（`RouteFlownRun()` / 旧走廊版 `RouteFlownPath()`）：
  - A 立管 = 层高 − 话筒高度（`Item::height`，吊装时它就是挂高）
  - B 吊顶 = 从话筒 (x, y) **水平**走到两侧墙之一：**由目标设备在哪一半决定**——
    设备 x < stage.w/2 → 左墙 (x = 0)，x > stage.w/2 → 右墙 (x = stage.w)，
    正好在中心线才退回「较近的一侧」。前 / 后墙（y = 0 / y = d）**不再使用**，
    所以 B 永远平行于台口，长度只沿 x 量：|话筒 x − 墙面 x|
  - C 沿墙 = 层高（下墙）
  - D 地面 = 从墙脚 (墙面 x, 话筒 y) 按走廊规则到设备
  - 总长 = A + B + C + D（无预留）
- 平面图只能画 B 和 D：B 段虚线（高于头顶），D 段实线；A / C 存在 `CableLink`
  的 `legUp / legWall` 里（`flown / ceilSegs / leg*` 字段一并写入 `.smproj`）。
- 悬停状态栏显示分段：「吊装 1.5 m + 吊顶 5.0 m + 沿墙 8.0 m + 地面 14.5 m = 29.0 m」
  （吊顶段就是 |话筒 x − 墙面 x|）。
- 吊装高度 > 层高 → 按层高计算并在状态栏提示。
- 01/02/05 的话筒旁画「吊」小徽标；锁定期间不能改吊装状态。

### 编组话筒汇集（Convergence）
- 立体声对 / 制式对 / Decca 树这类 `MicGroup` 仍然是**一条**线缆，但先**汇集**：
  - 汇集点 = 各成员位置的**平均**；Decca 树（3 只）取**左右两只的中点**，中置那只
    不参与平均（它本来就是往前突出的），但它照样有自己的汇集短线
  - 每个成员 → 汇集点：细虚线「汇集线」（`CableLink::collectorPaths`，不挂标签）
  - 汇集点 → 目标：**一条**主干（`CableLink::path`），标签只挂在这里，通道数 = 组员数
  - 长度 = 话筒高度 + Σ 汇集短线 + 主干（`CableRawLen()` 自动包含，`CollectorLen()`）
- 主话筒的多振膜（L/R、L/C/R）**不是**编组：它仍然每个振膜一条独立走线。

### 刷新一致性
所有会改动 `Project` 的路径统一走 `App::RefreshAfterProjectChange()`
（`SyncEdits + Layout + InvalidateAll`，并清空 `L_.chPickRow / L_.topoNodes /
L_.topoLinkRect` 等瞬态缓存）。页面数据全部在绘制时从 `Project` 重新推导
（通道表行、拓扑节点、线缆路径、容量行），因此切换页面不会看到旧数据。

### 项目文件（新增字段，旧文件仍可打开）
- `ceiling <m>`；`item` 记录末尾追加 `flown flyHeight`；
  `link` 记录末尾追加 `manual flown ceilSegs legUp legCeil legWall legFloor`；
  `topology <valid> <stale> <n>` + `topolink …`（同一套字段）。
- 命令行新增 `--auto`：启动后先执行一次「自动布线」（供脚本回归测试）。

### 走廊模型开关（Linear 默认 / Grid 试验）

### Grid 全局单调行号（最终对比）
- Grid 现在用**全页一个行号计数器**：所有话筒线按话筒 x 排序取最内侧行（0.45 + 0.15·k），
